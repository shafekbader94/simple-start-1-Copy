Build a NestJS project with a users module that supports CRUD operations. Use TypeORM with SQLite for data storage. Implement DTOs for user creation and updates, and define a User entity. The project should be structured for easy extension and maintainability.

Description:
This project is a NestJS backend application using TypeORM and SQLite. It features a modular architecture with a dedicated users module. The users module includes:

User entity for database mapping
DTOs for creating and updating users
RESTful endpoints for user management (create, read, update, delete)
SQLite database for development and testing
The codebase is organized for clarity, with separate folders for DTOs and entities, and is ready for further expansion (for example: adding authentication or more modules).
